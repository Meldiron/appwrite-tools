# 🧰 Appwrite tools

## 📝 Installation

Latest version:

```
go install github.com/Meldiron/appwrite-tools
```

Specific version:

```
go install github.com/Meldiron/appwrite-tools@v1.0.0
```

## 🎓 Usage

Interactive command:

```
appwrite-tools
```

Non-interactive command:

```
appwrite-tools \
    --action="backup" \
    --resource="users" \
    --endpoint="https://cloud.appwrite.io/v1" \
    --project-id="mail-memo" \
    --api-key="standard_a77a6f...ca65"
```
